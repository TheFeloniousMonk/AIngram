Using AIngram · Step 6

Bring in old memories

If your AI already keeps notes somewhere, like a Claude Project's files, you can bring them all in at once. Claude turns them into an import file, and you check and approve it on the admin page.

1. Have Claude make the import file

Open a chat that can see your old notes, such as one in the Claude Project that holds them, and give it this. Claude makes a file for you to download, so nothing needs copying out of the chat and nothing gets cut off.

Give this to Claude

Create a downloadable file named aingram-import.jsonl from this project's memory files. Each line is one JSON object with: subject (path-like, such as people/ada), kind (such as fact, breadcrumb, decision or correction), body (the full text from the source, everything, not a summary; write this first), excerpt (a compressed clue to the body, 300 characters at most; it's what boot shows), keywords (a list), and source (the file it came from). Where they apply, also add pinned (true only for what belongs in the always-present core), untrusted_ctx ("meadow", "web", or a list of both) and date (YYYY-MM-DD). Split each file by subject, one entry per fact line or section, and bring everything, not a summary. Breadcrumbs become one entry per dated block, of kind breadcrumb, with its date; mark those written after Meadow sessions with untrusted_ctx "meadow". If it is too large for one file, split it into aingram-import-1.jsonl, aingram-import-2.jsonl and so on, never splitting an entry.

The prompt mentions Meadow, a network where AIs talk to each other. If your AI doesn't use it, leave that part in; it simply won't apply.

2. Check it on the admin page

  1. Open the Import tab and choose the file

    Every line is checked against your policy, just as if the brain had written it.

  2. Read the preview

    You'll see how many notes there are by subject and kind, which ones will be pinned, and any problems. A problem names the line it's on, so you can ask Claude to fix that line.

  3. Click Import in wallet and sign

    Nothing is written until you sign. Then the whole file lands at once, or none of it does.

Got several files? Each one is checked, previewed and approved on its own.

What happens to imported notes

  • They're written as the brain, so pinned ones join its core.
  • Each keeps where it came from (the source), so you can always trace it back.
  • Each keeps its original date. An old breadcrumb arrives already faded, just as if it had been there all along.
  • Imports don't count against the brain's daily limit. Your signature on the whole file stands in for it.
