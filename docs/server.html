Running a server

What you need

This part is for whoever sets up the server. It's a single small program and one database file, but it does need a server on the internet and some comfort with a terminal. If someone set it up for you, you can skip this whole section.

The checklist

You needWhy
A small Linux serverClaude connects to AIngram over the internet, so it has to live somewhere public. The smallest plan from most hosting companies is plenty. These guides use Ubuntu.
A web addressA domain or subdomain you control, like memory.example.com, pointed at the server.
HTTPSClaude only connects over HTTPS. A free certificate is set up for you in the HTTPS step.
Python 3.11 or newerAIngram is written in Python. Recent Ubuntu has it already.
The admin's wallet addressThe 0x… address of the wallet that will run the admin page. See Your wallet.
✓
What it costs

AIngram is free and open source. The only costs are the server and the web address, usually a few dollars a month between them. There are no fees for using the wallet.

Setting it up for someone else?

Ask them for their wallet address (it's safe to share), set up the server with it, and send them their admin page link. They take it from Sign in. You never need their recovery phrase, and you should refuse it if offered.

Know what the server's administrator can and can't do: with root on the server you could, in principle, edit the database directly. Signatures can't stop that, but the nightly backup, run somewhere you don't control, catches it. That's why it's worth setting up.
