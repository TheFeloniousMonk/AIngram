Using AIngram · Step 4

Connect Claude

AIngram plugs into Claude as a connector. Claude in your chats becomes the brain. If you also use Claude Code, it gets its own key and writes as Code.

Find your connection address

On the admin page's Overview, under Connect an agent, copy the MCP endpoint. It's your server's address with /mcp on the end, like https://memory.example.com/mcp.

Claude: web, desktop and phone

  1. Add a custom connector

    In Claude, open Settings, then Connectors, and choose to add a custom connector. Name it AIngram and paste the connection address. If you don't see the option, Anthropic's help centre lists which plans include custom connectors.

  2. Click Connect

    Claude opens an approval page on your server. It names the connector and the voice it will get: the brain.

  3. Approve it with your wallet

    Pick your wallet and sign. Your wallet's message names your server, the connector and the voice. Then you're sent back to Claude, connected.

  4. Switch it on in a chat

    In a chat, make sure AIngram is turned on in the connectors or tools menu. Once added, it works in Claude on the web, the desktop app and your phone.

!
Approve only right after you clicked Connect yourself

Anyone can make a connector called "Claude" and send you a link to your approval page. Approving theirs would hand them your memory. The page shows how long ago the request was made; if you didn't just click Connect, click Don't connect.

The connection lasts 7 days and renews itself. It appears under Keys on the admin page, where you can switch it off at any time. If a chat seems stuck right after a renewal, start a new chat.

Claude Code

  1. Create a code key

    On the Keys tab, under New code key, give it a label you'll recognise, like "laptop", and click Create key. Sign in your wallet.

  2. Copy the command it shows you

    A window shows the key once, with a ready-made command. Copy the one marked Claude Code, in a terminal and run it. Or, to connect one project only, copy the .mcp.json settings into that project.

  3. Click I've saved it

    The key is never shown again, and it isn't stored anywhere you can get it back from. If you lose it, replace it from the Keys list.

!
Treat a code key like a password

Anyone with it can read your AI's memory and write as Code. Don't paste it into chats or commit it to a public repository. If one leaks, revoke it on the Keys tab; it stops working at once.
