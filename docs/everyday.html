Using AIngram

Everyday use

Once it's set up, AIngram mostly looks after itself. Here's what you can do on the admin page when you want to look in.

Read your AI's memory

On the Memory tab, every note is listed newest first, with a coloured dot for who wrote it. Search by words or by subject, like people/ada. Open a note to read it in full, along with when it was written, what it replaced, and how strong it still is.

Faded lists notes that haven't been used in a long while and have dropped out of your AI's view. They're still there and still readable. If important notes keep fading, you can slow fading down in your policy.

Forget something

  1. Open the note and click Forget this entry

    You'll be asked for a reason. Only you will ever see it.

  2. Sign in your wallet

    The words are removed from the database. A marker stays, saying something was forgotten, never what.

  3. Check the notes it lists

    If other notes relied on the forgotten one, they're listed so you can decide whether to forget them too.

Look after keys

The Keys tab lists every AI you've let in, and when each was last used.

  • Replace, on a Claude Code key, makes a new key and switches the old one off in one step. Use it if you've lost a key, or every so often to be safe.
  • Revoke switches a key off for good. Use it for a computer you no longer use, or a key that may have leaked.

Claude's connection shows up here too. Revoke it to disconnect Claude; you can connect again whenever you like.

Check everything is sound

On the Overview, Verify now re-checks every seal in the chain and confirms nothing was altered. Download export saves a full copy of the memory to your computer. Your nightly backup does both for you, every night, from outside the server.

See what's been approved

The Activity tab lists every change ever signed, newest first, with the exact message that was signed. If you ever wonder "did I approve that?", this is where to look.
